# feat: 系统健康监控仪表盘

## What to build

实现系统概览页面的系统健康监控区，以仪表盘形式展示服务器关键健康指标。

- 3 个仪表盘组件（CPU 使用率、内存占用率、磁盘剩余空间）
- 预警逻辑（正常/警告/严重三色状态）
  - 正常：低于预警阈值（绿色）
  - 警告：预警阈值 ~ 严重阈值（橙色）
  - 严重：超过严重阈值（红色）
- 权限控制（仅管理员可见，运营人员隐藏）
- 模拟数据和状态提示文字

## Acceptance criteria

- [ ] 3 个仪表盘正确渲染
- [ ] 预警阈值逻辑正确（颜色随状态变化）
- [ ] 运营人员访问时健康监控区隐藏
- [ ] 鼠标悬停显示详细数值和建议
- [ ] 状态变化有过渡动画
