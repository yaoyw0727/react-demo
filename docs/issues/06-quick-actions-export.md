# feat: 快速操作和数据导出

## What to build

实现系统概览页面的快速操作区，提供高频操作按钮和数据导出功能。

- 快速操作按钮组件（数据导出、系统备份、日志查看）
- 数据导出功能（使用 xlsx 库生成 Excel 文件）
  - 导出当前统计数据
  - 文件名格式：`系统概览_{YYYY-MM-DD_HH-mm-ss}.xlsx`
- 按钮权限控制（导出运营可用，备份/日志仅管理员）
- 导出 Loading 状态和成功提示

## Acceptance criteria

- [ ] 3 个操作按钮正确显示
- [ ] 点击数据导出生成并下载 Excel 文件
- [ ] 导出文件包含所有统计维度数据
- [ ] 运营人员看不到备份和日志按钮
- [ ] 导出过程显示 Loading 状态
- [ ] 导出成功显示提示消息
