# feat: 自动刷新和手动刷新

## What to build

实现系统概览页面的数据自动刷新和手动刷新功能。

- 自动刷新 Hook（5分钟间隔，可配置）
- 手动刷新按钮和 Loading 状态
- 数据获取 Hook（模拟 API 调用）
- 最后更新时间显示
- 后台静默刷新，避免 Loading 闪烁

## Acceptance criteria

- [ ] 页面加载后每 5 分钟自动刷新数据
- [ ] 点击刷新按钮手动刷新数据
- [ ] 刷新过程显示 Loading 状态
- [ ] 显示最后更新时间
- [ ] 刷新失败时显示错误提示
- [ ] 页面卸载时清除定时器
