# feat: 实时数据统计卡片

## What to build

实现系统概览页面的实时数据统计区，以数字卡片形式展示 4 项关键业务指标。

- 4 个统计卡片组件（在线用户数、今日访问量、订单总数、营收总额）
- 响应式网格布局（PC 4列 / 平板 2列 / 移动 1列）
- 模拟数据和数字格式化（千分位、货币格式）
- 点击卡片跳转到对应详情页面
- 卡片悬停效果和数字动画

## Acceptance criteria

- [ ] 4 个卡片正确显示，数据格式正确
- [ ] 响应式布局在各断点正常
- [ ] 点击卡片跳转到对应路由
- [ ] 鼠标悬停有视觉反馈
- [ ] 数值变化有滚动动画
- [ ] 深色模式下卡片样式适配

## Blocked by

- #1 系统概览页面骨架和路由
