# 页面需求文档 - 图表点击放大 (Chart Detail Modal)

**所属页面**: 系统概览 (`/system/overview`)  
**优先级**: P1  
**版本**: v1.0  
**创建日期**: 2026-05-21  
**状态**: ✅ 已完成

---

## 1. 需求概述

### 1.1 背景
当前系统概览页面的图表尺寸较小（高度 280px），用户无法查看具体数值细节。点击图表后弹出放大弹窗，提供详细数据表格和更大尺寸的图表展示，满足用户深入分析数据的需求。

### 1.2 目标
- ✅ 提供图表交互入口，点击即可查看详情
- ✅ 弹窗内展示放大图表和完整数据表格
- ✅ 保持与现有页面一致的视觉风格和交互体验

### 1.3 核心价值
| 价值维度 | 说明 |
|---------|------|
| **数据可读性** | 放大图表和表格让用户看清具体数值 |
| **交互体验** | 点击即看，关闭即走，不干扰主页面 |
| **信息完整** | 提供占比百分比等衍生数据 |

## 2. 功能详细需求

### 2.1 功能列表

| 功能项 | 说明 | 优先级 | 状态 |
|-------|------|--------|------|
| 图表点击事件 | 点击任一图表触发弹窗 | P0 | ✅ 已完成 |
| 弹窗展示 | 宽度 800px，包含图表+表格 | P0 | ✅ 已完成 |
| 折线图/柱状图详情 | 图表(400px) + 数据表格 | P0 | ✅ 已完成 |
| 饼图详情 | 图表(400px) + 数据表格(含占比) | P0 | ✅ 已完成 |
| 弹窗标题 | 显示图表名称 + 时间范围标签 | P1 | ✅ 已完成 |
| 弹窗关闭 | 点击遮罩层或关闭按钮 | P0 | ✅ 已完成 |

### 2.2 详细功能说明

#### 2.2.1 图表点击事件

**触发条件**: 点击任一图表区域（访问趋势、订单占比、地域分布）

**交互说明**:
- ✅ 鼠标悬停时图表区域显示 cursor: pointer
- ✅ 点击后打开 `ChartDetailModal` 弹窗
- ✅ 传入图表类型、标题、当前时间范围、对应数据

#### 2.2.2 弹窗展示

**弹窗规格**:
- 宽度: 800px
- 高度: 自适应内容
- 居中显示
- 支持点击遮罩层关闭
- 右上角显示关闭按钮

**弹窗内容结构**:
```
┌──────────────────────────────────────────────┐
│  访问趋势（周）                        [×]   │  ← 标题 + 关闭按钮
├──────────────────────────────────────────────┤
│                                              │
│           [放大图表 高度 400px]              │  ← ECharts 图表
│                                              │
├──────────────────────────────────────────────┤
│  详细数据                                    │  ← 表格标题
│  ┌────────────────────────────────────────┐  │
│  │ 时间/模块    │ 数值                    │  │  ← 数据表格
│  ├────────────────────────────────────────┤  │
│  │ 05-15        │ 1,200                   │  │
│  │ 05-16        │ 1,350                   │  │
│  │ ...          │ ...                     │  │
│  └────────────────────────────────────────┘  │
└──────────────────────────────────────────────┘
```

#### 2.2.3 折线图/柱状图详情

**数据表格结构**:

| 列名 | 说明 | 格式化 |
|-----|------|--------|
| 时间/模块 | X 轴标签 | 纯文本 |
| 数值 | Y 轴数值 | 千分位格式化 |

**示例（访问趋势）**:
| 时间 | 数值 |
|------|------|
| 05-15 | 1,200 |
| 05-16 | 1,350 |

**示例（订单占比）**:
| 模块 | 数值 |
|------|------|
| 电子产品 | 320 |
| 服装鞋帽 | 210 |

#### 2.2.4 饼图详情

**数据表格结构**:

| 列名 | 说明 | 格式化 |
|-----|------|--------|
| 地区 | 地区名称 | 纯文本 |
| 数值 | 用户数量 | 千分位格式化 |
| 占比 | 百分比 | 保留 1 位小数，如 `18.5%` |

**占比计算**: `占比 = (当前值 / 总值) * 100`

**示例（地域分布）**:
| 地区 | 数值 | 占比 |
|------|------|------|
| 广东 | 2,340 | 18.5% |
| 北京 | 1,890 | 15.0% |
| 上海 | 1,560 | 12.3% |

#### 2.2.5 弹窗标题

**格式**: `{图表名称}（{时间范围}）`

**示例**:
- `访问趋势（日）`
- `访问趋势（周）`
- `访问趋势（月）`
- `订单占比（周）`
- `地域分布（周）`

**时间范围标签映射**:
| 值 | 显示 |
|---|------|
| `day` | 日 |
| `week` | 周 |
| `month` | 月 |

#### 2.2.6 弹窗关闭

**关闭方式**:
- 点击右上角关闭按钮
- 点击遮罩层（弹窗外部区域）
- 按 `Esc` 键

**关闭行为**:
- 弹窗销毁或隐藏
- 不保留弹窗内部状态
- 不影响主页面数据

## 3. UI/UX 设计

### 3.1 组件层次结构

```
SystemOverviewWithExport
├── ... (现有页面内容)
└── ChartDetailModal (新增)
    ├── Modal (antd)
    │   ├── title: 图表名称 + 时间范围
    │   ├── width: 800px
    │   ├── maskClosable: true
    │   └── destroyOnHidden: true
    │   ├── ReactECharts (放大图表)
    │   └── Table (详细数据表格)
```

### 3.2 样式规范

| 元素 | 样式 | 说明 |
|-----|------|------|
| 图表容器 | `height: 400px` | 固定高度 |
| 数据表格 | 默认 antd Table 样式 | 可添加斑马纹 |
| 弹窗标题 | 16px, 加粗 | 与现有弹窗一致 |
| 表格标题 | 14px, 加粗, margin-bottom: 12px | 分隔图表和表格 |
