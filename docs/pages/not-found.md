# 页面需求文档 - 404 页面 (NotFound)

**页面路径**: `*` (catch-all 路由)  
**路由配置**: `{ path: '*', component: NotFound, title: '404', labelKey: 'common.notFound', hidden: true }`  
**滚动模式**: 不适用  
**优先级**: P0

---

## 1. 页面概述

### 1.1 页面定位

404 页面是系统的错误处理页面，主要职责：
- 处理用户访问不存在的路由
- 提供友好的错误提示
- 引导用户返回首页

### 1.2 目标用户

所有访问了不存在路径的用户。

### 1.3 核心价值

| 价值维度 | 说明 |
|---------|------|
| **错误提示** | 明确告知用户页面不存在 |
| **用户引导** | 提供返回首页的快捷入口 |
| **体验优化** | 避免浏览器默认错误页面 |

---

## 2. 功能需求

### 2.1 功能列表

| 功能项 | 说明 | 优先级 | 状态 |
|-------|------|--------|------|
| 404 状态显示 | 显示 404 错误状态 | P0 | 已实现 |
| 错误提示文字 | 显示页面不存在提示 | P0 | 已实现 |
| 返回首页按钮 | 导航回首页 | P0 | 已实现 |

### 2.2 详细功能说明

#### 2.2.1 404 状态显示

**功能描述**: 使用 antd Result 组件显示 404 错误状态

**交互说明**:
- 使用 `Result` 组件，`status="404"`
- 标题显示 "404"
- 组件自动显示 404 图标和样式

#### 2.2.2 错误提示文字

**功能描述**: 显示页面不存在的提示文字

**交互说明**:
- 使用 `subTitle` 属性显示提示文字
- 文字通过国际化 key `common.notFound` 获取
- 支持中英文切换

#### 2.2.3 返回首页按钮

**功能描述**: 提供导航回首页的按钮

**交互说明**:
- 使用 `extra` 属性渲染按钮
- 按钮样式: `type="primary"` 主按钮
- 按钮文字通过国际化 key `common.backToHome` 获取
- 点击后使用 `navigate('/')` 导航回首页

### 3.1 页面布局

│                                     │

### 3.2 组件层次结构

```
NotFound
└── Result
    ├── status="404"
    ├── title="404"
    ├── subTitle={t('common.notFound')}
    └── extra

```

### 3.3 样式规范

本页面**不使用** CSS Module，完全使用 antd Result 组件的内置样式。

## 5. 交互流程

### 5.1 404 触发流程

```
1. 用户访问不存在的路径
2. React Router 匹配 catch-all 路由
3. 渲染 NotFound 组件
4. 显示 404 错误页面
```

### 5.2 返回首页流程

```
1. 用户点击 [返回首页] 按钮
2. onClick 触发 navigate('/')
3. React Router 导航到 /
4. 渲染 Home 页面
```
