一、基础信息提示

明确需求的核心定位与目标受众，为AI提供基础框架：

我需要为公司内部管理系统新增一个「系统概览」功能页面，面向系统管理员和运营人员。请基于以下想法生成一份专业的PRD文档。


二、核心功能描述

详细拆解页面需展示的图形与统计信息，确保AI精准理解需求：

页面需包含以下核心模块：
1. **实时数据统计区**：展示在线用户数、今日访问量、订单总数、营收总额4项关键指标，以数字卡片形式呈现，支持点击查看详情。
2. **趋势分析图表**：用折线图展示近7日用户访问趋势，柱状图展示各业务模块订单占比，饼图展示用户地域分布。图表需支持时间范围切换（日/周/月）。
3. **系统健康监控**：以仪表盘形式展示服务器CPU使用率、内存占用率、磁盘剩余空间，指标异常时自动标红预警。
4. **快速操作入口**：提供数据导出、系统备份、日志查看3个高频操作按钮，点击直接跳转对应功能页面。


三、交互与体验要求

补充页面交互逻辑与视觉规范，提升PRD的可执行性：

交互细节：
1. 所有图表支持鼠标悬停显示具体数值，点击可放大查看详情。
2. 数据每5分钟自动刷新，支持手动刷新按钮。
3. 页面响应式设计，适配PC端与平板设备。
视觉要求：
1. 采用公司统一的蓝色主题色，图表配色需区分度高且符合品牌规范。
2. 布局遵循「重要信息优先」原则，核心统计数据置于页面顶部。


四、非功能需求

明确性能、安全等约束条件，完善PRD的完整性：

非功能需求：
1. 页面加载时间≤2秒，数据刷新延迟≤1秒。
2. 仅系统管理员角色可查看服务器监控模块，运营人员无权限。
3. 支持数据导出为Excel格式，导出文件需包含所有统计维度。


五、AI指令收尾

引导AI生成标准化PRD文档：

请按照标准PRD格式生成文档，包含以下章节：背景与目标、用户故事、功能详细需求、交互设计、非功能需求、验收标准、技术建议。文档语言需专业严谨，符合互联网产品规范。
