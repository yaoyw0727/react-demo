# 产品需求文档 - 系统概览 (System Overview)

**页面路径**: `/system/overview`  
**路由配置**: `{ path: '/system/overview', component: SystemOverview, title: '系统概览', labelKey: 'menu.systemOverview', icon: <DashboardOutlined /> }`  
**父级路由**: `/system` (系统管理)  
**滚动模式**: 模式一（整区滚动）+ 图表区域自适应  
**优先级**: P0  
**版本**: v1.0  
**创建日期**: 2026-05-21

---

## 1. 背景与目标

### 1.1 项目背景

随着公司业务规模的扩大，内部管理系统的使用频率和数据量持续增长。当前系统缺乏一个集中展示关键指标和系统健康状态的概览页面，管理员和运营人员需要进入多个子页面才能获取完整信息，效率低下且不利于快速决策。

### 1.2 产品目标

| 目标维度 | 具体指标 | 说明 |
|---------|---------|------|
| **信息集中化** | 一屏展示 4 项核心指标 + 3 个图表 | 减少跨页面查询次数 |
| **决策效率提升** | 关键信息获取时间 < 10 秒 | 重要数据置顶展示 |
| **监控实时化** | 数据自动刷新间隔 ≤ 5 分钟 | 及时发现系统异常 |
| **操作便捷化** | 高频操作一键直达 | 减少操作路径 |

### 1.3 目标用户

| 用户角色 | 使用场景 | 核心需求 |
|---------|---------|---------|
| **系统管理员** | 日常系统巡检、异常监控 | 查看系统健康状态、快速处理异常 |
| **运营人员** | 业务数据分析、报表导出 | 查看业务指标趋势、导出数据报告 |

### 1.4 价值主张

| 价值维度 | 说明 |
|---------|------|
| **全局视野** | 一屏掌握系统运行状态和业务关键指标 |
| **实时感知** | 自动刷新机制确保数据时效性 |
| **快速响应** | 异常预警 + 快捷操作入口提升响应速度 |
| **数据驱动** | 多维度图表辅助业务决策 |

### 3.2 实时数据统计区

#### 3.2.1 功能描述

以数字卡片形式展示 4 项关键业务指标，支持点击查看详情。

#### 3.2.2 数据卡片清单

| 卡片名称 | 数据字段 | 单位 | 刷新频率 | 详情跳转 |
|---------|---------|------|---------|---------|
| 在线用户数 | `onlineUsers` | 人 | 实时 | `/system/user?status=online` |
| 今日访问量 | `todayVisits` | 次 | 5 分钟 | `/analytics/visits?range=today` |
| 订单总数 | `totalOrders` | 单 | 5 分钟 | `/product/orders` |
| 营收总额 | `totalRevenue` | 元 | 5 分钟 | `/finance/revenue` |

#### 3.2.3 卡片设计规范

**布局**: 4 列等宽网格布局，响应式断点：
- PC (≥1200px): 4 列
- 平板 (768px-1199px): 2 列
- 移动 (<768px): 1 列

**卡片结构**:
```
┌─────────────────────┐
│  📊 图标             │
│  在线用户数          │  ← 标题
│  1,234              │  ← 数值（大字号）
│  ↑ 12% 较昨日       │  ← 环比变化（可选）
└─────────────────────┘
```

**交互说明**:
- 鼠标悬停: 卡片轻微上浮 + 阴影加深
- 点击: 跳转到对应详情页面
- 数值更新: 数字滚动动画（duration: 500ms）

#### 3.2.4 数据模型

```typescript
interface StatCard {
  key: string;          // 卡片唯一标识
  title: string;        // 卡片标题
  value: number;        // 当前数值
  unit?: string;        // 单位（可选）
  icon: React.ReactNode;// 图标
  trend?: {             // 环比趋势（可选）
    value: number;      // 变化百分比
    direction: 'up' | 'down'; // 变化方向
  };
  detailPath: string;   // 详情页路由
}
```

### 3.3 趋势分析图表区

#### 3.3.1 功能描述

展示多维度业务趋势图表，支持时间范围切换和图表交互。

#### 3.3.2 时间范围切换器

**组件**: `Segmented` 分段控制器

**选项**:

| 选项 | 值 | 说明 |
|-----|-----|------|
| 日 | `day` | 展示今日每小时数据 |
| 周 | `week` | 展示近 7 日每日数据 |
| 月 | `month` | 展示近 30 日每日数据 |

**交互说明**:
- 切换时间范围后，所有图表数据同步更新
- 切换时显示 Loading 状态
- 默认选中"周"

#### 3.3.3 访问趋势折线图

**图表类型**: 折线图（Line Chart）

**数据维度**:

| 维度 | 说明 |
|-----|------|
| X 轴 | 时间（小时/日期） |
| Y 轴 | 访问次数 |
| 数据系列 | 1 条（总访问量） |

**交互功能**:
- 鼠标悬停: 显示 Tooltip（时间 + 访问次数）
- 点击: 放大查看详细信息
- 数据点: 显示圆形标记

**示例数据**（周视图）:
```typescript
[
  { date: '2026-05-15', visits: 1200 },
  { date: '2026-05-16', visits: 1350 },
  { date: '2026-05-17', visits: 1100 },
  { date: '2026-05-18', visits: 1500 },
  { date: '2026-05-19', visits: 1420 },
  { date: '2026-05-20', visits: 1680 },
  { date: '2026-05-21', visits: 1550 },
]
```

**图表类型**: 柱状图（Bar Chart）

**数据维度**:

| 维度 | 说明 |
|-----|------|
| X 轴 | 业务模块名称 |

### 3.4 系统健康监控区

#### 3.4.1 功能描述

以仪表盘形式展示服务器关键健康指标，异常时自动预警。

#### 3.4.2 监控指标清单

| 指标 | 数据字段 | 单位 | 预警阈值 | 严重阈值 |
|-----|---------|------|---------|---------|
| CPU 使用率 | `cpuUsage` | % | > 70% | > 90% |
| 内存占用率 | `memoryUsage` | % | > 75% | > 90% |
| 磁盘剩余空间 | `diskFree` | GB | < 50GB | < 20GB |

#### 3.4.3 仪表盘设计规范

**布局**: 3 列等宽网格布局

**仪表盘结构**:
```
┌─────────────────────┐
│     ╱  75%  ╲       │  ← 弧形进度条
│    ╱         ╲      │
│   │    75%    │     │  ← 中心数值
│    ╲         ╱      │
│     ╲_______╱       │
│  CPU 使用率          │  ← 指标名称
│  ⚠️ 警告             │  ← 状态提示
└─────────────────────┘
```

**颜色规范**:

| 状态 | 条件 | 颜色 |
|-----|------|------|
| 正常 | 低于预警阈值 | 绿色 (#52c41a) |
| 警告 | 预警阈值 ~ 严重阈值 | 橙色 (#fa8c16) |
| 严重 | 超过严重阈值 | 红色 (#f5222d) |

**交互功能**:
- 鼠标悬停: 显示详细数值和建议操作
- 点击: 查看该指标历史趋势
- 状态变化: 颜色过渡动画

#### 3.4.4 预警机制

**预警规则**:

| 级别 | 触发条件 | 响应动作 |
|-----|---------|---------|
| 警告 | 指标达到预警阈值 | 仪表盘变橙色 + 显示警告图标 |
| 严重 | 指标达到严重阈值 | 仪表盘变红色 + 显示警告图标 + 提示消息 |

**提示消息示例**:
- 警告: "CPU 使用率较高，建议检查运行中的服务"
- 严重: "CPU 使用率过高，请立即处理！"

### 3.5 快速操作区

#### 3.5.1 功能描述

提供 3 个高频操作按钮，点击直接跳转对应功能页面。

#### 3.5.2 操作按钮清单

| 按钮名称 | 图标 | 跳转路径 | 权限要求 | 说明 |
|---------|------|---------|---------|------|
| 数据导出 | `DownloadOutlined` | 触发导出功能 | 运营+ | 导出当前统计数据为 Excel |
| 系统备份 | `CloudServerOutlined` | `/system/backup` | 管理员 | 进入系统备份页面 |
| 日志查看 | `FileTextOutlined` | `/system/logs` | 管理员 | 查看系统操作日志 |

#### 3.5.3 数据导出功能

**导出范围**:
- 实时数据统计区 4 项指标
- 趋势分析图表区 3 个图表数据
- 导出时间戳

**导出格式**: Excel (.xlsx)

**文件名格式**: `系统概览_{YYYY-MM-DD_HH-mm-ss}.xlsx`

**交互流程**:
```
1. 用户点击 [数据导出] 按钮
2. 显示 Loading 状态
3. 后端生成 Excel 文件
4. 浏览器自动下载文件
5. 显示成功提示
```

### 7.3 数据获取建议

**API 设计**:

| 接口 | 方法 | 路径 | 说明 |
|-----|------|------|------|
| 获取概览数据 | GET | `/api/overview/stats` | 返回 4 项指标 |
| 获取趋势数据 | GET | `/api/overview/trends?range=week` | 返回图表数据 |
| 获取健康数据 | GET | `/api/overview/health` | 返回服务器指标 |
| 导出数据 | POST | `/api/overview/export` | 返回 Excel 文件流 |

**数据缓存策略**:
- 使用 React Query 或 SWR 进行数据缓存
- 缓存时间: 5 分钟（与自动刷新间隔一致）
- 后台静默刷新，避免 Loading 闪烁

### 7.4 状态管理建议

**本地状态**:

| 状态 | 类型 | 说明 |

| `timeRange` | `day \| week \| month` | 当前时间范围 |
| `isRefreshing` | `boolean` | 是否正在刷新 |
| `lastUpdateTime` | `Date` | 最后更新时间 |

**全局 Store** (可选):
- 如需要跨页面共享数据，可使用 Zustand
- 否则建议使用 React Query 服务端状态管理

### 7.5 性能优化建议

### 7.6 代码示例

**数据获取 Hook**:

```typescript
import { useState, useEffect, useCallback } from 'react';

export const useOverviewData = (timeRange: 'day' | 'week' | 'month') => {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  const fetchData = useCallback(async () => {
    setLoading(true);
    try {
      const [stats, trends, health] = await Promise.all([
        fetch(`/api/overview/stats`).then(r => r.json()),
        fetch(`/api/overview/trends?range=${timeRange}`).then(r => r.json()),
        fetch(`/api/overview/health`).then(r => r.json()),
      ]);
      setData({ stats, trends, health });
    } catch (err) {
      setError(err);
    } finally {
      setLoading(false);
    }
  }, [timeRange]);

  useEffect(() => {
    fetchData();
  }, [fetchData]);

  return { data, loading, error, refresh: fetchData };
};
```

**自动刷新 Hook**:

```typescript
import { useEffect, useRef } from 'react';

export const useAutoRefresh = (callback: () => void, interval: number = 300000) => {
  const savedCallback = useRef(callback);

  useEffect(() => {
    savedCallback.current = callback;
  }, [callback]);

  useEffect(() => {
    const tick = () => savedCallback.current();
    const id = setInterval(tick, interval);
    return () => clearInterval(id);
  }, [interval]);
};
```
